# NOVA DIGITAL website

Static site: HTML5, CSS3, JavaScript, Bootstrap 5.3 (CDN).

- Open `index.html` in a browser, or serve the folder with any static host.
- Styles: `assets/css/style.css` (colors are CSS variables at the top).
- Behavior: `assets/js/main.js` (theme, filter, form validation).
- Replace the example domain in the HTML, `robots.txt` and `sitemap.xml` before launch.
- The contact form validates on the front end only; connect it to Formspree, Netlify Forms or your backend.
